# StockSense AI (45)

Design a premium AI-powered investment operating system named "StockSense AI". The design should feel like a mix of Bloomberg Terminal, TradingView, TIKR, FinChat, Notion, and Linear. Use a modern dark theme with emerald green accents, subtle glassmorphism, rounded cards (16–20px radius), clean typography (Inter or Geist), soft shadows, and smooth micro-interactions.

Create a responsive desktop-first web application with the following pages:

1. Dashboard

- Market overview cards (Nifty, Sensex, Bank Nifty, Gold, Bitcoin, USDINR)

- Market heatmap

- Top gainers/losers

- Watchlist

- AI insights panel

- Portfolio summary

- Upcoming earnings calendar

- Sector performance cards

2. Stock Explorer

- Powerful search bar

- Advanced filters (PE, ROE, ROCE, Market Cap, Revenue Growth, Debt, Dividend Yield, RSI, MACD, Volume)

- Table view and card view

- Save custom screeners

- Watchlist integration

3. Stock Detail Page

- Hero section with company profile

- Interactive TradingView-style price chart

- Tabs: Overview, Financials, Ratios, Technicals, AI Analysis, News, Peers, Shareholding, Quarterly Results, Annual Reports

- AI Bull vs Bear thesis

- Fundamental, Technical, Momentum, and Risk scores

- Key metrics displayed as modern KPI cards

4. Portfolio

- Holdings table

- Allocation by sector

- Diversification score

- Portfolio health score

- AI recommendations

- Performance charts

- Risk analysis

5. Trading Journal

- Timeline of trades

- Trade creation form

- Entry, exit, quantity, stop loss, target

- Trade type (Long-term, Swing, Intraday, Futures, Options)

- Strategy tags

- Confidence slider

- Mood selector

- Chart screenshot uploads

- Post-trade review and lessons learned

6. AI Coach

- Chat interface similar to ChatGPT

- Suggested prompts

- Portfolio review

- Stock comparison

- Personalized investing guidance

7. Behavioral Analytics

- Trading performance dashboard

- Mistake detection

- Win/loss analysis

- Psychological patterns

- Risk discipline score

- Personalized do's and don'ts

- Best performing sectors, setups, and holding periods

Design the UI to be minimal, premium, data-rich, and suitable for professional investors. Focus on readability, dense but organized financial information, beautiful charts, elegant tables, and intuitive navigation. Avoid clutter while maintaining a Bloomberg-grade information architecture.
